A promotion with zero concepts writes a valid package, and the confirm says "No concepts attached."
The promote confirm reads: "This hands a package to Warp. It will show up in Warp's review queue."
The lane value is lowercase on every door and in the package (apparel, content, story); the page shows the labels capitalised.
Reference images live under an uploads folder per idea and travel in the promoted package.
Rules for the package, set by Jeremy on Nov 21. The package holds only the concepts the promoter ticked, in the order they ticked them. A ticked concept that is not one of the idea's own concepts is an error, and no package is built. Concept files are named concept-1, concept-2 and so on in that order, and reference images are named ref-1, ref-2 and so on in the order they were stored. Each keeps its own file ending. A promotion with no concepts still carries the idea's reference images. People appear by display name and never by email. A submitter or promoter with an @ in it is a person, and anything else is a system name, which is shown as it is. A person with no display name is an error, and no package is built. The time is written in UTC, to the second, ending in Z. The scout block is filled only when the idea's source is scout: finding_id is the idea's source_ref and motive is its scout_motive. evidence_url is always null for now, because Hopper does not store one yet. An idea with no lane or no reviewer notes has null for them. With no concepts, the promote confirm adds "No concepts attached." after its sentence.
